Admin REY Chord Songbook

Halaman untuk pengelola. Menyiapkan file lagu, lalu diunggah ke GitHub.

Buka Songbook

1. Daftar lagu yang sudah ada

Dimuat otomatis dari songs/index.json kalau halaman ini dibuka lewat alamat web. Kalau dibuka dari komputer, pilih file index.json secara manual.

Memuat…

2. Tambah satu lagu

3. Impor banyak file teks sekaligus

Pilih banyak file .txt. Nama file dibaca sebagai judul. Kalau memakai pola Artis - Judul.txt, bagian sebelum tanda "-" menjadi artis.

4. Lagu baru (belum diunggah)

    Belum ada lagu baru.

    1. Ekstrak zip, isinya folder songs/ (file lagu + index.json yang sudah diperbarui).
    2. Salin isi folder itu ke folder REY Chord Songbook/songs/, timpa index.json yang lama.
    3. Commit dan push ke GitHub. Tunggu satu sampai dua menit, lalu muat ulang Songbook.
